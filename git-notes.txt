README.md 
git restore - правка еще не в коммите, значит можно отменить изменения в файле 
git checkout <хеш> - переключает проект на состояние выбранного коммита, чтобы посмотреть старую версию файлов. Вместо <хеш> нужно указать код коммита без угловых скобок.
Detached HEAD - появляется когда указывает на старый коммит после команды git checkout <хеш>
git revert - отменяет изменения коммита с помощью нового коммита 
git switch -c — создаёт новую ветку и сразу переключает на неё
git merge - обьеденяет изменения с другой ветки в ветку где я нахожусь 
Fast-forward - перемотка вперед когда обьеденяем ветки, если в main не было новых коммитов
git branch -d - удаляет ветку после обьеденения 
конфликт слияния - это когда у нас в ветках есть два разных варианта одной строки и при обьеденении возникает конфликт какой вариант выбрать
